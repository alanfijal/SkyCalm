# Design decisions

For team review, 24 November 2026. The proposed region is **Europe (Stockholm)**. The first release will answer one passenger question: where along this estimated route does the weather model suggest bumps?

## Weather and passenger forecasts

| Choice | Reason and trade-off |
| --- | --- |
| NOAA GFS 0.25° pressure-grid product | Four UTC cycles (00, 06, 12, 18), with winds, temperature, geopotential height and surface CAPE. For the demo sample every third forecast hour from 0 to 36 inclusive. A smooth timeline interpolates a coarse model in space and time. Small local or short-lived turbulence can be missed. ECMWF open IFS also offers 0.25° products, multiple cycles, pressure-level winds, temperature, height and most-unstable CAPE. Changing providers requires validating the CAPE definition and recalibrating the thresholds. [GFS registry](https://registry.opendata.aws/noaa-gfs-bdp-pds/) · [ECMWF fields, cycles and licence](https://www.ecmwf.int/en/forecasts/datasets/open-data) |
| Read indexed messages and crop in the task | Read each NOAA `.idx`, select UGRD/VGRD/TMP/HGT at 200, 250, 300, 350 and 400 hPa plus surface CAPE and height. The next offset determines an inclusive byte range ending one byte before it. Use object length for the final record. Require HTTP 206 and validate the returned byte range, size and field identities. Retain a halo around Europe for derivatives and normalize longitudes. GRIB offsets select complete global messages. The geographic crop happens after decoding. In the 24 Nov 2026 00 UTC index, the 13 leads had 286 selected messages totalling **187,319,883 bytes**, calculated from index offsets only. [Observed f000 index](https://noaa-gfs-bdp-pds.s3.us-east-1.amazonaws.com/gfs.20261124/00/atmos/gfs.t00z.pgrb2.0p25.f000.idx) |
| Forecast readiness | Phase 1 permits an explicit refresh. In Phase 3 the NOAA NewGFSObject SNS topic in us-east-1 supports SQS. Subscribe a Stockholm queue with a source-ARN-restricted policy, a verified message-body filter for the 0.25° product and a finite admission window. Check completeness across leads even when a notification arrives twice or arrives early. If the shared topic policy or safe filtering cannot be proved, use a bounded cycle-aligned index check and record the decision. [NOAA notification topic](https://registry.opendata.aws/noaa-gfs-bdp-pds/) · [Cross-region SNS delivery](https://docs.aws.amazon.com/sns/latest/dg/sns-cross-region-delivery.html) |
| Route and baseline | Pin a dated OurAirports snapshot, filter to scheduled service and apply the same Europe box to both endpoints. The great-circle estimate is reproducible and needs no paid flight schedule. Compute Ellrod TI1 from horizontal deformation and vertical wind shear using physical distances and geopotential-height differences. Use a separate CAPE indicator during climb/descent and label its coverage as a proxy. Use four versioned ordinal categories. Show unavailable wherever neither method has support. Calibrated probabilities and fitted explanations arrive with Phase 5 evidence. [Airport data and terms](https://ourairports.com/data/) · [Data dictionary](https://ourairports.com/help/data-dictionary.html) |
| AWC observations and OpenSky traffic | Archive timestamped worldwide SIGMETs and available pilot/aircraft reports. AWC describes reports as primarily US/North Atlantic. Its rolling API cannot supply an arbitrary historical classroom day on demand. Start capture in Phase 2, or document a permitted archive. Use OpenSky only after written permission for an operational live service, including teaching use. Keep this optional layer off pending permission and label its status. Demonstrate real SIGMETs regardless. [AWC data API](https://aviationweather.gov/data/api/) · [OpenSky terms](https://opensky-network.org/about/terms-of-use) |
| Poll limits | If licensed, one server-side OpenSky client shares an EU traffic layer. Use two-minute scheduled polls during a bounded window. Our box costs four credits per request, so continuous two-minute polling would consume 2,880 credits/day before retries against the standard 4,000. Reserve credits atomically before every attempt. Observe the actual quota, refresh OAuth client credentials using token expiry and one retry on 401, honor 429 retry-after and back off when absent. Keep only the fields the approved aggregate layer needs. [API credits and authentication](https://openskynetwork.github.io/opensky-api/rest.html) · [Scheduler timing](https://docs.aws.amazon.com/scheduler/latest/UserGuide/schedule-types.html) |

## Runtime, identity and delivery

| Choice | Alternative considered and consequence |
| --- | --- |
| React/Vite static PWA, TypeScript, MapLibre GL and deck.gl | A static build needs no web server. MapLibre supplies map navigation and deck.gl the route and moving marker. Pin a redistributable basemap, serve project assets locally and show attribution. Tailwind and shadcn/ui provide consistent controls. Add Motion only for interactions that benefit from it. A keyboard-controlled timeline, text equivalents for every intensity and reduced-motion mode remain usable without the globe. |
| HTTP API and Python 3.12 arm64 Lambda | Validate input and coverage in the handler. Keep the public weather API cacheable per run. Route searches with itinerary details and all personal requests go direct to Stockholm, uncached. In Phase 6 WAF checks public forecast assets at CloudFront. An origin-request signer using temporary credentials can call only the public weather GET routes through API Gateway IAM. This prevents anonymous direct calls to the protected origin. Regional routes use their own throttles and user routes require JWT. [AWS origin-signing design](https://aws.amazon.com/blogs/security/protect-apis-with-amazon-api-gateway-and-perimeter-protection-services/) |
| One-shot Fargate and ECR | ecCodes and xarray decode native GRIB in a pinned image. Fargate allows longer jobs than Lambda and the image exits when complete. Use an x86 image, 1 vCPU, 2 GiB initially, one task at a time, a hard task deadline and StopTask on timeout. Benchmark on the real grid in Phase 1. No long-running ECS service. |
| Network | Propose a task with temporary public IPv4 in a public subnet, zero inbound rules, no listening port and outbound HTTPS. Use free regional S3/DynamoDB gateway endpoints, scoped task/execution roles and TLS. This accepts wider outbound destinations. Private subnets require ECR API, ECR Docker, Logs and optionally Secrets Manager interfaces per AZ. They also require a separate non-VPC fetcher to copy external NOAA ranges into EU S3. Regional gateways alone cannot reach the US source. [Fargate networking](https://docs.aws.amazon.com/AmazonECS/latest/developerguide/fargate-task-networking.html) · [S3 gateway scope](https://docs.aws.amazon.com/vpc/latest/privatelink/vpc-endpoints-s3.html) · [Network costs](costs.md) |
| EventBridge, Step Functions Standard and SQS | A custom bus routes domain events. A Standard execution waits for the finite ECS job and keeps an inspectable execution history. SQS buffers per-flight work with a DLQ and absorbs retries independently of the weather publisher. Transactions plus a DynamoDB Streams outbox handle state changes and publication retries. Replays carry a separate namespace. Choosing simple direct Lambda calls would make delayed retries and demo progress harder to inspect. |
| S3, DynamoDB, Glue and Athena | Private S3 stores versioned weather, observations and model artifacts. DynamoDB on demand serves current-run pointers, user-owned watches, idempotency and inbox records. Define the Glue schema and a scan-limited Athena workgroup. Statistics use aggregate historical data and display sample counts. Apply TTL to personal records and explicit lifecycle rules by weather prefix. Pin only approved nonpersonal demo inputs. |
| Cognito and account privacy | Authorization code + PKCE, client with no secret, scoped access JWTs, 15-minute access tokens and refresh-token rotation. Keep both tokens in memory and accept reauthentication after reload via managed login. Derive ownership from verified `sub`. Require both `admins` membership and `skycalm/admin` on control endpoints. Google federation, push providers and email delivery can process metadata outside the EU. Review provider terms with the team before Phase 4, keep itineraries off those channels and offer the EU-hosted inbox. If strict residency cannot be met, request a scope decision. |
| Reminders and notifications | One-time Scheduler jobs at departure minus 24h and 3h, with automatic removal after completion. On late saves schedule only future reminders. Reconcile edits/deletes and re-read flight version, owner and consent before delivery. Use Web Push with a VAPID secret, then SES fallback under explicit opt-in. Expire invalid endpoints and distinguish provider acceptance from receipt on the demo phone. Explicitly delete schedules/subscriptions on account deletion, enforce arrival + 7 days in queries immediately and use DynamoDB TTL for eventual reclamation. |
| SageMaker, LightGBM and SHAP | On-demand Processing → Training → evaluation Processing → Model Registry via Step Functions, reusing the team's workflow tooling. Train on explicit turbulence reports, including explicit “none”. Match by time, level and location with forecast issue time before the report. Use chronological splits with held-out days, remove duplicate reports and keep related observations together. Compare class-weighted LightGBM with the physics baseline on Europe and North Atlantic separately, reporting per-class precision/recall, macro F1, calibration, confusion matrices, support and reporting bias. Broader training coverage may require a separately bounded historical extract outside the product box. Promote only when European holdout macro F1 improves, moderate/severe recall does not regress and there is adequate class support. Otherwise retain the baseline and report uncertainty. Emit `model.approved`, pin artifact digest once per grid run and map SHAP contributions to plain language. |
| Bedrock plus a template | Send only anonymous structured segments to direct in-region Nova Lite. Validate the 2–4 sentences against input quantities, categories and allowed claims. Fall back to a deterministic template on validation failure or timeout. Cache by route/run/result hash and version. Tuning, scheduled ML retraining and real-time endpoints require a separate cost review. |
| Operational evidence | Use seven-day JSON logs, opaque run/flight IDs, alarms for DLQs, queue age, failed workflows and failed tasks. Filter sensitive fields from logs. Inspect CloudTrail management history and costed event coverage. GuardDuty foundational monitoring in Phase 6 needs account-level approval, including any automatic trial behavior. A Phase 3 operator uses a local control view with an IAM-signed backend until Phase 4 Cognito group/scope enforcement exists. Never expose the Phase 3 control actions anonymously. |
| Git and Terraform | Use short feature branches, frequent logical commits and reviewed PRs. Split Terraform files by service in reusable modules, with one dev environment and a separate recoverable bootstrap. Pin Terraform/provider and actions, commit the provider lock, use private versioned encrypted S3 state with native locking and keep secrets, plans and local context outside Git. PRs run local checks. Trusted plans use a restricted OIDC role. Apply a reviewed saved plan for the exact commit through an approval gate, serialize by state and require a separate destroy review. P0 CI checks its executable cost model. Terraform and product CI start with their first source files. [S3 backend](https://developer.hashicorp.com/terraform/language/backend/s3) |
